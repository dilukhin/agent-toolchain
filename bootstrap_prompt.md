# Bootstrap prompt

Используй этот prompt только для запуска готового `opencode_setup`; не воспроизводи setup вручную и не читай/не выводи секреты.

```text
Получи или безопасно обнови рабочую копию dilukhin/opencode_setup. Не делай reset/clean при локальных изменениях.

1. Запусти штатный setup в режиме проверки: Windows `setup_windows.ps1 -Check`, Linux `setup_linux.sh --check`.
2. Сообщи найденные `modified/conflict`. Не уничтожай локальные изменения и unknown/BMAD skills.
3. Если нет конфликта, блокирующего безопасное применение, запусти обычный setup.
4. Снова запусти `-Check`/`--check`.
5. Сообщи итоговые состояния и оставшиеся конфликты. Не показывай содержимое `api-key.txt`.

Не запускай реальную удалённую ssh_relay-задачу. BMAD устанавливай только отдельно, если дан явный путь проекта.
```
