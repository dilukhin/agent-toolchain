# Bootstrap prompts

Используйте эти промпты только из клонированного `opencode_setup`. Агент должен запускать готовые скрипты, а не воспроизводить их командами вручную.

## Windows

```text
Проверь git status репозитория opencode_setup. Не читай и не выводи секреты. Запусти setup_windows.ps1. Скрипт обязан сохранить существующие api-key.txt, opencode.jsonc и AGENTS.md. После выполнения проверь PowerShell exit code и сообщи путь к placeholder API key без его содержимого. BMAD не устанавливай без явного пути проекта. Если я передам путь проекта, запусти install_bmad_windows.ps1 с этим путем и затем validate_bmad.js. Не копируй BMAD из других локальных проектов.
```

## Linux

```text
Проверь git status репозитория opencode_setup. Не читай и не выводи секреты. Запусти setup_linux.sh. Скрипт обязан сохранить существующие api-key.txt, opencode.jsonc и AGENTS.md и назначить API key права 0600. После выполнения проверь exit code и права файла, не показывая его содержимое. BMAD не устанавливай без явного пути проекта. Если я передам путь проекта, запусти install_bmad_linux.sh с этим путем и затем validate_bmad.js. Не копируй BMAD из других локальных проектов.
```

## Что делает setup

1. Устанавливает OpenCode CLI.
2. Устанавливает `@opencode-ai/plugin@1.15.4`, который является SDK плагинов и не устанавливает BMAD.
3. Создает отсутствующую RouterAI-конфигурацию с 13 проверенными model IDs.
4. Сохраняет существующие ключи и пользовательские конфиги.
5. По отдельной явной команде ставит project-local BMAD из официального `bmad-method@6.8.0` и проверяет 44 skills.

Поврежденные Bash-строки с префиксами `177:` и `138:` из прежней версии удалены вместе с дублирующей ручной реализацией.
